# Code of Conduct

We want a community where rules experts, beginners, designers and agent builders can disagree with evidence and remain respectful.

Be welcoming, assume good faith, cite sources for rules claims, and criticize ideas rather than people. Harassment, discrimination, doxxing, cheating tools, hidden-information exploits, sexualized language and sustained disruption are not accepted.

Maintainers may edit or remove harmful contributions and restrict participation when necessary. Report conduct issues privately to the repository owner. Enforcement will prioritize safety, context, proportionality and a clear explanation to affected participants.
